# Supabase для Kaspi Tracker

Облако нужно только для связки двух телефонов. Без него приложение работает как раньше.

## Настройка (один раз)

1. Создай **новый отдельный** проект в Supabase, только под это приложение.
2. Authentication → Sign In / Providers → включи **Allow anonymous sign-ins**.
3. SQL Editor → New query → вставь содержимое [`schema.sql`](schema.sql) → Run.
4. Project Settings → API: скопируй **Project URL** и **anon public** key в `local.properties` в корне репозитория:

   ```
   supabase.url=https://xxxx.supabase.co
   supabase.anonKey=eyJ...
   ```

   `local.properties` не попадает в git.
5. Проверь права доступа: `python supabase/check_rls.py` должен напечатать `RLS OK`.
6. Пересобери APK: ключи попадают в сборку через `BuildConfig`.

## Что лежит в облаке

Только операции (сумма, тип, мерчант, категория, название карты, «общее», «не в статистике»), имя и цвет профиля, связь пары. Сырой текст пушей и чеков, правила категорий и бэкапы остаются на телефоне.

## Если проект «уснул»

Бесплатный проект Supabase ставится на паузу после ~7 дней без запросов. Пока приложения синхронизируются, этого не случится. Если случилось: панель Supabase → проект → **Restore**. Приложение в это время показывает «Сервер не отвечает».
